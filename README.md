# Miro Shell

Custom shell made with [Quickshell](https://quickshell.org/) under [Hyprland](https://hypr.land/).

This repo contains quickshell configuration files only, for the environment configuration check out [here](https://github.com/davmarc-lab/personal).

## Installation
Before launching the shell the user need to execute the `install.sh` script.
> It downloads the required resources
```bash
chmod +x install.sh && ./install.sh
```
